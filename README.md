# Dave has moved

This repository is a **redirect stub** — it contains no application code.

Dave now lives at **https://github.com/drorlazar/Dave**
and is served at **https://drorlazar.github.io/Dave/**

## Why this stub exists

`Dave` was transferred from `DrorLazar-Sett` to the `drorlazar` account.
GitHub redirects old *repository* URLs after a transfer, but it does **not**
redirect GitHub **Pages** URLs — `https://drorlazar-sett.github.io/Dave/`
would simply 404, breaking old bookmarks and links.

This stub restores that URL and forwards every request to the new home,
preserving any sub-path, `?query` string and `#hash`
(the `/dave` helper relies on `?server=localhost:7778&file=...`).
